# NetGuard

## Requirements

- Windows 10/11
- [Python 3.11 or later](https://www.python.org/downloads/) installed and available on PATH

## How to run

1. Download/clone this repository.
2. Right-click **`Start_NetGuard.cmd`** (or `Start_NetGuard.ps1`) and select **"Run as administrator"**.
3. The first run will automatically create a local virtual environment and install dependencies — this might take a while. Subsequent runs start instantly.
4. The NetGuard desktop app window will open automatically.
